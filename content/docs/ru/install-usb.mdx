# Загрузка с USB

Можно записать ISO на USB-флешку и загрузить с неё настоящий компьютер.

<Callout type="warning">
**Экспериментально.** UzOS создана и проверена для виртуальных машин. На реальном железе текстовая консоль обычно работает, а мышь и графический рабочий стол (`startx`) могут не работать. Запись ISO **стирает всё** на флешке.
</Callout>

## Что нужно

- USB-флешка (любого объёма больше 64 МБ). Данные на ней будут удалены.
- Компьютер, который умеет загружаться в режиме **Legacy BIOS** (он же **CSM**). Большинство компьютеров, выпущенных до 2020 года, это умеют; на новых этот режим, возможно, придётся включить в настройках прошивки.

## Linux

1. Вставьте флешку и найдите её имя:

   ```
   lsblk
   ```

   Найдите диск подходящего размера, например `/dev/sdb`. **Будьте внимательны**: выбор не того диска уничтожит его данные.

2. Запишите ISO (замените `/dev/sdX` на вашу флешку):

   ```
   sudo dd if=UzOS.iso of=/dev/sdX bs=4M status=progress conv=fsync
   ```

## Windows

1. Скачайте [Rufus](https://rufus.ie) и запустите его.
2. **Device**: ваша USB-флешка. **Boot selection**: `UzOS.iso`.
3. **Partition scheme**: `MBR`. **Target system**: `BIOS (or UEFI-CSM)`.
4. Нажмите **Start**. Если Rufus спросит, как записать образ, выберите **DD Image mode**.

## Загрузите компьютер с флешки

1. Вставьте флешку в нужный компьютер и включите его.
2. Откройте меню загрузки, обычно клавишей **F12**, **F11**, **F8** или **Esc** (клавиша ненадолго показывается при включении).
3. Выберите USB-флешку. Если пунктов два, выберите тот, в названии которого **нет** `UEFI`.
4. GRUB запустит UzOS. Войдите как `root` / `uzos`.

Чтобы вернуться в обычную систему, выключите компьютер и выньте флешку.
