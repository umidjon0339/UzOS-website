# Сборка из исходников

Сборка UzOS своими руками занимает около минуты. Нужен Linux (или WSL2 в Windows).

## 1. Установите инструменты

| Инструмент | Для чего |
| --- | --- |
| `make` | Запускает сборку |
| `gcc` с поддержкой 32 бит | Компилирует код на C (`-m32`) |
| `nasm` | Ассемблирует файлы `.s` |
| `grub-mkrescue`, `xorriso`, `mtools` | Создают загрузочный ISO |
| `qemu-system-i386` | Запускает результат |

**Ubuntu / Debian**

```
sudo apt install build-essential gcc-multilib nasm grub-pc-bin grub-common xorriso mtools qemu-system-x86
```

**Arch / Manjaro**

```
sudo pacman -S base-devel nasm grub libisoburn mtools qemu-system-x86
```

## 2. Получите код

```
git clone https://github.com/umidjon0339/UzOS.git
cd UzOS
```

## 3. Соберите и запустите

```
make          # собрать kernel.bin
make run      # запустить его в QEMU
```

## Все цели make

| Команда | Что делает |
| --- | --- |
| `make` | Собирает `kernel.bin` |
| `make run` | Запускает `kernel.bin` в QEMU |
| `make iso` | Собирает загрузочный `UzOS.iso` (для VirtualBox или USB) |
| `make check` | Проверяет, что у ядра правильный заголовок Multiboot |
| `make clean` | Удаляет всё, что создала сборка |

## Где что лежит

```
boot/      первые инструкции, настройка GRUB, скрипт компоновщика
arch/      особенности x86: GDT, IDT, TSS, прерывания, переход в режим пользователя
lib/       небольшие помощники: строки, форматирование, разбор аргументов
modules/   само ядро, по папке на каждую подсистему управления
userland/  пример программы (hello.c), работающей в режиме пользователя
```

Все модули устроены одинаково: `core/` для частей, которые вызывает ядро, `commands/` с папкой на каждую команду оболочки, `syscalls/` с папкой на каждый системный вызов и `security/` для пар «атака — защита». Подробнее — [Как устроена UzOS](/ru/docs/modules).

<Callout type="tip">
Объектные файлы попадают в `build/`, повторяя дерево исходников, поэтому в папках с исходниками лежит только код. Изменение заголовочного файла автоматически запускает пересборку.
</Callout>
