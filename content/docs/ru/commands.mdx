# Команды оболочки

В UzOS 83 команды. Многие из них называются и выводят результат так же, как в Linux, поэтому то, что вы выучите здесь, пригодится и там. Подробности — командой `help <команда>` внутри UzOS.

## Оболочка

| Команда | Что делает |
| --- | --- |
| `help [команда]` | Какие есть команды |
| `clear` | Очистить экран и буфер прокрутки |
| `echo <текст>` | Вывести текст обратно |
| `calc <выражение>` | Целочисленный калькулятор, например `calc (2+3)*4` |
| `color <fg> [bg]` | Сменить цвет текста |
| `history` | Введённые до сих пор команды |
| `uzfetch` | Слева флаг, справа сведения о системе |
| `statusbar [on\|off]` | Показать или скрыть верхнюю панель |
| `snake` | Классическая «змейка» в текстовом режиме |

## Файлы

| Команда | Что делает |
| --- | --- |
| `ls [путь]` | Содержимое каталога, с владельцами и правами |
| `cd [путь]` | Сменить каталог (без пути — домой) |
| `pwd` | Показать текущий каталог |
| `cat <путь>` | Вывести файл целиком |
| `touch <путь>` | Создать пустой файл |
| `write <путь> <текст>` | Заменить содержимое файла |
| `mkdir <путь>` | Создать каталог |
| `rm <путь>` | Удалить файл или пустой каталог |
| `cp <откуда> <куда>` | Скопировать файл |
| `mv <откуда> <куда>` | Переместить или переименовать |
| `wc <путь>` | Посчитать строки, слова и байты |
| `grep <слово> <путь>` | Вывести строки, содержащие слово |
| `hexdump <путь> [байты]` | Показать файл побайтно |

## Пользователи и права

| Команда | Что делает |
| --- | --- |
| `whoami` | От имени какого пользователя работает оболочка |
| `id [пользователь]` | uid, имя и домашний каталог пользователя |
| `users` | Все учётные записи |
| `su [пользователь]` | Стать другим пользователем |
| `logout` | Вернуться к приглашению входа |
| `passwd [пользователь]` | Сменить пароль |
| `chmod <режим> <путь>` | Кто может читать и писать файл |
| `chown <пользователь> <путь>` | Отдать файл другому пользователю |
| `useradd <имя>` | Создать учётную запись (только root) |
| `userdel <имя>` | Удалить учётную запись (только root) |

## Процессы

| Команда | Что делает |
| --- | --- |
| `ps` | Снимок списка процессов |
| `exec <файл> [&]` | Загрузить и запустить программу ELF, например `exec /hello` |
| `kill <pid>` | Остановить процесс |
| `spawn` | Запустить фоновый рабочий процесс |
| `sleep <секунды>` | Пауза (Ctrl+C прерывает её) |
| `testuser [null\|badptr]` | Запустить крошечную программу в ring 3 |

## Процессор и планирование

| Команда | Что делает |
| --- | --- |
| `top`, `htop`, `btop` | Процессор и процессы в реальном времени (`q` — выход) |
| `lscpu`, `cpuinfo` | Что за процессор и как он настроен |
| `nproc`, `getconf` | Число процессоров и размеры системы |
| `uptime` | Время работы, пользователи и load average |
| `vmstat`, `mpstat`, `pidstat`, `sar`, `cpustat` | На что ушло время процессора |
| `nice`, `renice` | Запустить или изменить процесс с другим приоритетом |
| `chrt` | Посмотреть и задать политику планирования (FIFO, RR, ...) |
| `taskset`, `numactl` | Привязка к процессору и размещение NUMA |
| `ulimit` | Ограничения ресурсов |
| `time <команда>` | Сколько выполнялась команда |
| `perf stat\|record\|report` | Подсчёт событий и поиск, где процессор тратит время |
| `faults` | Исключения процессора и процессы, которые они завершили |
| `cpupower`, `turbostat`, `powerprofilesctl` | Частота, состояния простоя, профиль питания |
| `systemctl`, `systemd-cgtop` | Службы и потребляемые ими ресурсы |
| `cpucalls` | Проверить каждый системный вызов CPU из ring 3 |

## Память

| Команда | Что делает |
| --- | --- |
| `meminfo` | Занятая и свободная физическая RAM |
| `heapinfo` | Обойти кучу ядра |
| `memtest` | Проверить `sbrk`, `mmap` и `munmap` |
| `pagewalk <адрес>` | Проследить адрес по таблицам страниц |
| `ioinfo [pid]` | Открытые файловые дескрипторы процесса |

## Устройства и экран

| Команда | Что делает |
| --- | --- |
| `devices` | Оборудование и счётчики его прерываний |
| `date` | Дата и время из часов реального времени |
| `mode [имя]` | Список режимов экрана или переключение, например `mode 1280x720` |
| `theme [имя]` | Список цветовых тем или переключение |
| `font [uzos\|bios]` | Показать или сменить шрифт консоли |
| `startx` | Графический рабочий стол (выход — ESC) |
| `beep [hz]`, `play` | Тон или мелодия на PC-динамике |

## Безопасность

| Команда | Что делает |
| --- | --- |
| `seclab` | Лаборатория безопасности, см. [Лаборатория безопасности](/ru/docs/security-lab) |
| `audit [sum]` | Что и кому запретили защиты |
| `caps [пользователь]` | Какие привилегии есть у пользователя |
| `integrity` | То же ли это ядро, что загрузилось? |

Файлы в `/proc` пишет ядро в момент чтения: попробуйте `cat /proc/cpuinfo`, `cat /proc/stat` или `cat /proc/<pid>/status` с PID из `ps`.
