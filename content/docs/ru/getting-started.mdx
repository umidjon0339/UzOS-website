# Первый запуск

На этой странице показано, что вы увидите при запуске UzOS и что ввести в первую очередь. Если вы ещё не запустили систему, сначала откройте [Запуск в QEMU](/ru/docs/install/qemu).

## 1. Загрузка

1. **GRUB** показывает меню с одним пунктом *UzOS*. Через 3 секунды система запускается сама (или нажмите Enter).
2. Ядро выводит **журнал загрузки**: по строке `[ OK ]` на каждую часть (таймер, клавиатура, память, страничная адресация, пользователи, планировщик...).
3. Появляется **приглашение входа**: `uzos login:`

## 2. Вход в систему

В UzOS две учётные записи:

| Пользователь | Пароль | Что может |
| --- | --- | --- |
| `root` | `uzos` | Всё (все capabilities) |
| `guest` | `guest` | Обычный пользователь: только свои файлы и процессы |

Введите имя пользователя, нажмите Enter, затем введите пароль. Приглашение показывает, кто вы и где находитесь: `root@uzos:~#` для root, `guest@uzos:~$` для обычного пользователя.

## 3. Первые команды

```
help              список всех команд
help ls           справка по одной команде
uzfetch           сводка о системе рядом с флагом
ls /              файлы в корневом каталоге
cat /proc/cpuinfo сведения о процессоре, их пишет ядро
ps                запущенные процессы
meminfo           сколько RAM занято и свободно
top               процессор в реальном времени (выход: q или Ctrl+C)
```

## 4. Полезные клавиши

| Клавиша | Что делает |
| --- | --- |
| `Tab` | Дополнить команду или путь |
| `Up` / `Down` | Листать ранее введённые команды |
| `Ctrl+C` | Очистить строку или остановить запущенную команду |
| Колесо мыши | Прокрутить консоль назад |
| `Ctrl+Up` / `Ctrl+Down` | Увеличить / уменьшить разрешение экрана |

Пока вы печатаете, имя команды становится **зелёным**, если такая команда есть, и **красным**, если ни одна команда так не начинается.

## 5. Рабочий стол

```
startx
```

`startx` открывает небольшой графический рабочий стол с окном *System Monitor*. Перетаскивайте окна за заголовок, щёлкните по окну, чтобы поднять его наверх. Нажмите **ESC**, чтобы вернуться в оболочку.

## 6. Пользователи

```
whoami            кто я?
su guest          стать guest (пароль: guest)
logout            вернуться к приглашению входа
passwd            сменить свой пароль
```

<Callout type="note">
UzOS хранит файлы на **RAM-диске**. Всё, что вы создадите, пропадёт при выключении машины. Чтобы выйти, просто закройте окно виртуальной машины.
</Callout>
